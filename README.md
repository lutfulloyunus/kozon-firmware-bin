# Qozon datchigi — proshivka fayllari

Bu repoda faqat qurilmalar yuklab oladigan tayyor fayllar bor:

- `firmware/version.json` — oxirgi versiya
- `firmware/kozon.bin` — proshivka

ESP32 qurilmalar bu yerni har 6 soatda tekshiradi va yangi versiya bo'lsa o'zini yangilaydi.
Fayllar avtomatik `publish.sh` orqali chiqariladi — qo'lda o'zgartirmang.
